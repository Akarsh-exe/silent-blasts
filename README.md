# Silent Blasts

A client-side Fabric mod for Minecraft 1.21.11 that filters specific blast
sound events. Reduces audio clutter during fast gameplay without touching
anything server-side.

## What it does

- Mutes specific blast sound events locally on your client
- Client-side only — no gameplay changes, no hitbox or damage changes
- No server modifications, no detection by other players

## Requirements

- Minecraft 1.21.11
- Fabric Loader
- Fabric API

## Install

1. Install Fabric Loader for Minecraft 1.21.11
2. Drop Fabric API into your `mods/` folder
3. Drop `silent-blasts-1.0.0.jar` into the same folder
4. Launch with the Fabric profile

## Download

Grab the latest jar from the [releases](https://github.com/Akarsh-exe/silent-blasts/releases) page,
or download it directly from the mod page (link coming soon).

## Fair play

This mod is a client-side sound filter. It does not reveal hidden information,
automate gameplay, or provide any unfair advantage. Sound muffler mods are
explicitly allowed on major PvP servers — see Leg.GG's modification guidelines
and OGCraft's client mod policy.
